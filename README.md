# Portfolio Personnel 🖥️

**Langages : HTML, CSS, PHP, JavaScript, YAML**

Ce projet est un **portfolio personnel** permettant de présenter mes compétences, domaines, projets et niveaux de manière claire et structurée. Il utilise un fichier YAML pour centraliser les informations et génère dynamiquement le contenu du site.  

---

## Fonctionnalités principales
- **Présentation personnelle** : Informations sur moi, contact et introduction.  
- **Domaines de compétence** : Chaque domaine (ex : développement, réseau, bureautique, langues) est affiché avec ses items.  
- **Items et niveaux** : Chaque compétence possède un niveau décrit avec des termes clairs (Débutant, Intermédiaire, Avancé) et représenté visuellement.  
- **Gestion via YAML** : Toutes les compétences, niveaux et projets sont stockés dans un fichier YAML, facilitant les mises à jour sans modifier le code PHP.  
- **Interface web dynamique** : La page affiche automatiquement les domaines et items à partir du YAML.  
- **Sections supplémentaires** : Possibilité d’ajouter des projets, réalisations, ou expériences professionnelles.  
- **Navigation fluide** : Menu clair pour accéder rapidement aux différentes sections du portfolio.  
- **Responsive** : Le site est accessible sur différents écrans (PC, tablette, mobile).  

---

## Contenu du projet
- `index.php` : Page d’accueil qui charge les informations depuis le fichier YAML.  
- `assets/` : Contient les fichiers CSS et JS pour le style et l’interactivité.  
- `data/portfolio.yaml` : Fichier YAML central contenant toutes les informations des domaines, items et niveaux.  
- `images/` : Dossier pour les images utilisées dans le portfolio (avatars, icônes, captures de projets).  
- `templates/` : Modèles PHP pour générer dynamiquement les sections du site.  

---

## Objectif
Le portfolio a pour objectif de :  
1. Présenter mes **compétences techniques et linguistiques**.  
2. Permettre une **mise à jour facile** grâce au fichier YAML.  
3. Offrir une **interface propre et lisible** pour un recruteur ou toute personne intéressée par mon parcours.  
4. Centraliser toutes mes réalisations dans un **seul site web interactif et évolutif**.
